## Назначение и ожидаемая работа
«Заметки» — приложение для создания, редактирования, поиска, закрепления, удаления и отправки текстовых заметок. Данные должны сохраняться локально и переживать закрытие приложения. Пользователь хочет исправления ошибок, проверку на iOS 27.2 beta и IPA для самостоятельной подписи и установки.

## Основные файлы
- Sources/NotesApp.swift — вход приложения.
- Sources/Note.swift — заметка, заголовок, превью, даты и счётчики.
- Sources/NotesViewModel.swift — список заметок, поиск и порядок сохранения.
- Sources/NotesFileStore.swift — чтение и атомарная запись JSON.
- Tests/ — 12 XCTest-проверок хранения.
- scripts/ — сборка, подготовка симулятора и проверка IPA.
- Sources/NotesListView.swift — список и переход к редактору.
- Sources/NoteDetailView.swift — редактор и отправка текста.
- Resources/Info.plist — метаданные приложения.
- project.yml — конфигурация XcodeGen.
- .github/workflows/build_ipa.yml — существующая облачная сборка.
- NotesApp.ipa — проверенный исходный неподписанный архив.

## Зависимости, запуск и внешние средства
Используются системные библиотеки Apple, macOS, Xcode 27.2, Python 3 и XcodeGen. Сборка выполнена через GitHub Actions в среде xcode-27. Установка выполняется пользователем через 3uTools либо аналог. Само приложение не обращается к внешним серверам.
Для установки XcodeGen на Mac с Homebrew: brew install xcodegen. Для тестов и сборки: bash scripts/build_ipa.sh. Для запуска в Xcode: xcodegen generate, затем открыть NotesApp.xcodeproj и выбрать схему NotesApp. Полные команды — в README.md. На Windows доступны проверки IPA, но нет Xcode.

## Что реализовано
- Редактирование текстовых заметок и автоматическое сохранение с задержкой 0,5 секунды.
- Локальный JSON, поиск, закрепление, удаление и системное меню отправки.
- Светлая и тёмная тема средствами системного интерфейса.
- Сборка неподписанного IPA через GitHub Actions.
Хранение проверено автоматическими тестами в симуляторе iOS 27.2. Работа интерфейса и установка на личном телефоне ещё не подтверждены.

## Диагностика установки 12 октября
Пользователь сообщил: в 3uTools подпись проходит, установка завершается общим сообщением «не удалось установить приложение». После уточнения подтвердил, что для установки выбирал исходный NotesApp.ipa из проекта, а не файл из папки подписанных IPA.
Проверенный исходный IPA не имеет профиля подписи, каталога _CodeSignature и команды LC_CODE_SIGNATURE в исполняемом файле. Такой исходный файл требуется сначала подписать, затем устанавливать именно выходной подписанный файл.
Пользователю предложено открыть Open Signed IPA Location в 3uTools и выбрать файл оттуда. Результат установки подписанного файла пока неизвестен. Другие возможные препятствия не исключены.

## Находки первоначальной диагностики до исправлений
1. При ошибке чтения/разбора minimal_notes.json массив остаётся пустым. Инициализация создаёт пример и сохраняет его поверх существующего файла: риск потери заметок.
2. После удаления всех заметок при следующем запуске создаётся демонстрационная заметка. Не различаются первый запуск и намеренно пустой архив.
3. Сохранение откладывается на 0,5 секунды, но обработчика ухода приложения в фон нет. Последние изменения могут не успеть сохраниться.
4. Ошибки чтения/записи выводятся только в консоль, пользователь их не видит.
5. JSON кодируется и записывается в основном потоке. На большом архиве это может тормозить ввод; измерений на устройстве пока нет.
6. При закрытии редактора удаляются все пустые заметки, а не только текущий незаполненный черновик. Сохранение при этом вызывается дважды.
7. project.yml содержит info.path без properties: XcodeGen генерирует Info.plist заново. В IPA действительно отсутствуют заданные в исходном plist русское отображаемое имя, UILaunchScreen и настройки сцен/ориентаций. Это отдельный дефект конфигурации, а не доказанная причина отказа установки.
8. Автоматических тестов нет; текущий workflow выбирает Xcode 16, а не Xcode 27.2.
9. Команды git status/diff в текущем исполнителе возвращали «this operation must be run in a work tree», хотя git rev-parse определяет рабочую папку и core.bare=false. Конфигурация Git не менялась, наличие сторонних изменений нужно перепроверить перед будущими правками.

## Решения первоначальной диагностики
- Корень проекта определён по .git, исходникам и project.yml.
- Отделять ошибку выбора неподписанного файла от ошибок самого приложения.
- Исправления выполнять по исходникам с новой сборкой, сохраняя JSON и Bundle ID.
- Старый IPA оставить без изменений.
- Добавлены AGENTS.md и этот файл; README.md уточнён, особенно различие исходного и подписанного IPA.
- Исходники, настройки сборки, GitHub и приложение на телефоне в ходе диагностики не изменялись.

## Согласованный объём исправлений
Пункты 1–6 выполнены. Пункт 7 остаётся пользовательской проверкой.
1. Защитить существующие данные при ошибках чтения, различать первый запуск и пустой архив, показывать ошибки сохранения.
2. Сохранять незавершённые изменения при уходе в фон; сократить лишние записи и вынести запись большого архива из основного потока с сохранением порядка операций.
3. Убирать только текущий пустой черновик, проверить переходы и возврат из меню отправки без потери текста.
4. Исправить генерацию Info.plist и подготовить сборку с проверкой реально установленного Xcode/SDK 27.2; не выдавать сборку старым SDK за проверку новой beta.
5. Добавить проверки хранения: существующий JSON, повреждённый JSON без перезаписи, пустой архив, последовательные изменения, ошибка записи.
6. Собрать новый неподписанный IPA на доступном Mac или после отдельного разрешения через GitHub Actions. Проверить содержимое и передать пользователю для подписи.
7. Пользователь проверяет установку, создание/поиск/редактирование, уход в фон, повторный запуск и сохранность данных на своём iPhone.

## Известные ограничения готовой версии
- Успешные тесты симулятора и сборка не подтверждают установку, подпись или работу на личном iPhone.
- Сохранена минимальная iOS 15; старые версии iOS отдельно не тестировались.
- Общего экспорта всех заметок нет. Важный текст можно сохранить через «Поделиться».
- Измерения скорости и памяти на большом архиве реального телефона не выполнялись.
- Xcode сообщил предупреждение о неполном наборе ориентаций для многозадачности iPad; портрет и горизонтальные ориентации исходной конфигурации сохранены. На iPad проверка не проводилась.
- XCTest в Xcode 27.2 предупреждает, что его библиотека требует более новую систему, чем минимальная iOS тестовой цели. Все тесты выполнены на симуляторе 27.2; это предупреждение не относится к зависимости самого приложения.
- Для загрузки симулятора beta используется публичный каталог Apple. Если Apple перестанет публиковать эту сборку или изменится среда GitHub, настройку потребуется обновить.
