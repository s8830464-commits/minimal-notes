# 📝 Minimal Notes для iOS (SwiftUI + IPA сборщик)

Минималистичное нативное приложение для заметок в чистом стиле iOS без лишних элементов.

---

## ✨ Возможности
- **Стиль Apple**: чистый интерфейс, поддержка темной и светлой темы.
- **Умный заголовок**: первая строка автоматически становится заголовком, остальной текст — превью.
- **Быстрый поиск**: поиск по содержимому и заголовкам заметок на лету.
- **Закрепление (Pin)**: свайп вправо для закрепления важных заметок вверху списка.
- **Удаление**: свайп влево для быстрого удаления.
- **Поделиться**: нативная кнопка «Поделиться» (Share Sheet) для отправки текста в Telegram/сообщения.
- **Локальное хранение**: все данные хранятся локально в формате JSON в песочнице приложения, полная приватность.

## 🚀 Как получить файл `.ipa` бесплатно через GitHub:

1. Создайте **новый пустой репозиторий** на [GitHub](https://github.com/new) (например, с именем `minimal-notes`).
2. В папке проекта запустите файл `push_to_github.bat` (или выполните команды в терминале):
   ```bash
   git init
   git branch -M main
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/ВАШ_ЛОГИН/minimal-notes.git
   git push -u origin main
   ```
3. Откройте ваш репозиторий на GitHub и перейдите во вкладку **Actions**.
4. Сборка **Build iOS IPA** запустится автоматически. Она займет ~1–2 минуты.
5. Нажмите на завершенную сборку и внизу в разделе **Artifacts** скачайте архив `NotesApp-ipa.zip`.
6. Распакуйте скачанный zip — внутри будет готовый файл **`NotesApp.ipa`**!

## 📲 Как установить `.ipa` на iPhone:

### Через SideStore:
1. Отправьте `NotesApp.ipa` на ваш iPhone (через AirDrop, Telegram «Избранное» или iCloud Drive).
2. Откройте приложение **SideStore** на телефоне.
3. Перейдите во вкладку **My Apps** -> нажмите значок **`+`** в верхнем углу.
4. Выберите `NotesApp.ipa`. SideStore переподпишет приложение вашим Apple ID и установит его.

### Через 3uTools:
1. Подключите iPhone к компьютеру кабелем и откройте 3uTools.
2. Перейдите в раздел **Toolbox** -> **IPA Signature** (Подпись IPA).
3. Добавьте `NotesApp.ipa`, выберите **Sign with Apple ID** (введите ваш Apple ID).
4. Нажмите **Start Signing**.
5. После завершения подписи перейдите в **Apps** -> **Install IPA** и выберите подписанный файл.
