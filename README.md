# Заметки (NotesApp / Minimal Notes)

Приложение для текстовых заметок на iPhone и iPad: создание, редактирование, поиск, закрепление, удаление и отправка текста через «Поделиться». Данные хранятся локально в Documents/minimal_notes.json внутри приложения.

## Текущее состояние
Подготовлены исходники версии 1.0.1 (сборка 2) с исправлениями сохранения и сборки для проверки на iOS 27.2 beta. Итог облачной сборки и проверок записывается в PROJECT_STATUS.md. До успешного завершения Actions новый IPA не считается готовым.

Старый NotesApp.ipa в корне оставлен без изменений. Это неподписанная версия 1.0, собранная с SDK iOS 18. Она не содержит новые исправления.

## Что исправлено в исходниках
- Ошибка чтения существующего файла больше не приводит к его замене примером.
- После удаления всех заметок архив остаётся пустым при следующем запуске.
- Последние изменения сохраняются при уходе приложения в фон и выходе из редактора.
- Записи выполняются последовательно; обычное сохранение не выполняет файловую работу на основном потоке.
- Пользователь видит ошибки хранения и может повторить операцию.
- Закрытие редактора убирает только текущую пустую заметку.
- Редактор использует общий текст заметки без повторной загрузки черновика при показе меню отправки.
- На iOS 16 и новее используется NavigationStack; для iOS 15 сохранена прежняя навигация.
- Настройки Info.plist больше не заменяются автоматически при генерации проекта.

Эти изменения не означают, что найдены все возможные ошибки. Установка и работа на вашем iPhone требуют отдельной проверки.

## Как подписать и установить через 3uTools
1. Подключите и разблокируйте iPhone. Подтвердите доверие компьютеру, если появится запрос.
2. В 3uTools откройте Toolbox → IPA Signature («Инструменты» → «Подпись IPA»).
3. Добавьте новый NotesApp-1.0.1-unsigned.ipa из dist или из скачанного артефакта GitHub Actions.
4. Выберите свой Apple ID или свой сертификат с профилем. Для подписи с Apple ID выберите именно подключённый телефон. Вход выполняйте самостоятельно в программе.
5. Дождитесь успешного завершения подписи.
6. Нажмите **Open Signed IPA Location («Открыть папку подписанных IPA»)**.
7. В разделе установки приложений выберите **файл из этой папки**, то есть результат подписи.

Исходный IPA остаётся неподписанным. Если выбрать его повторно вместо результата подписи, обычный iPhone откажет в установке.

Для запуска с подписью разработчика может потребоваться «Настройки» → «Конфиденциальность и безопасность» → «Режим разработчика», перезагрузка и подтверждение. Если телефон попросит довериться разработчику, выполните запрос в настройках управления устройством.

При повторной ошибке сохраните её полный текст. Не удаляйте приложение с заметками без резервной копии. Для обновления желательно сохранить тот же идентификатор приложения и учётную запись подписи.

Согласно документации 3uTools, бесплатная подпись Apple ID обычно действует 7 дней. Затем потребуется повторная подпись.
- [Инструкция 3uTools](https://www.3u.com/tutorial/articles/12092/how-to-use-ipa-sign)
- [Режим разработчика Apple](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)

## Как пользоваться
Кнопка с карандашом создаёт заметку. Первая непустая строка становится заголовком. Поиск работает по тексту; свайп вправо закрепляет запись, влево удаляет. В редакторе есть отправка текста, закрепление и удаление. Кнопка «Готово» закрывает клавиатуру и сохраняет изменения.

Если файл заметок не удалось прочитать, редактирование заблокировано, чтобы не испортить данные. Кнопка «Повторить чтение» пробует открыть тот же файл ещё раз. Она не удаляет его и не создаёт новый вместо повреждённого.
Если запись не удалась, текст остаётся в памяти и появляется сообщение. Не закрывайте приложение, пока не удалось повторить сохранение или скопировать важный текст.

## Где что находится
- Sources/ — исходники приложения.
- Tests/ — проверки хранения на Swift/XCTest.
- Resources/Info.plist — имя, версия и другие параметры.
- project.yml — описание проекта для XcodeGen.
- scripts/build_ipa.sh — тесты, сборка и упаковка на Mac.
- scripts/validate_ipa.py — проверка структуры неподписанного IPA.
- scripts/tests/ — тесты проверки упаковки; работают и на Windows.
- .github/workflows/build_ipa.yml — сборка в GitHub Actions.
- dist/ — новая сборка и сведения о проверке после успешной сборки; не отправляется в Git.
- PROJECT_STATUS.md — фактический результат работы и оставшиеся задачи.

## Как собрать через GitHub
Workflow Build iOS IPA запускается при отправке в main, master или codex/notes-ios27-fixes; также доступен ручной запуск Actions → Build iOS IPA → Run workflow.

Он использует среду xcode-27 и Xcode 27.2. Сначала проверяются SDK и симулятор iOS 27.2, затем выполняются тесты, собирается приложение для настоящего iPhone и проверяется IPA.
Если нужной версии Xcode или симулятора нет, сборка остановится с ошибкой. Старая версия SDK не будет выдана за iOS 27.2.

После успешной сборки скачайте артефакт NotesApp-1.0.1-unsigned:
- NotesApp-1.0.1-unsigned.ipa — для самостоятельной подписи.
- ipa-validation.json — параметры и SHA-256 файла.
- build-info.txt — версии Xcode/SDK и исходный commit.
- SHA256SUMS.txt — контрольная сумма.

Скрипт push_to_github.bat оставлен как старый способ первоначальной загрузки. Для обычной установки IPA он не нужен: он меняет origin и отправляет файлы.

## Как собрать на своём Mac
Нужны Xcode 27.2 с SDK и симулятором iOS 27.2, Python 3 и XcodeGen. При установленном Homebrew:

~~~sh
brew install xcodegen
~~~

Откройте Xcode для установки компонентов. Затем в терминале из папки NotesApp:

~~~sh
export DEVELOPER_DIR=/Applications/Xcode_27.2.app/Contents/Developer
bash scripts/build_ipa.sh
~~~

Если Xcode установлен под другим именем, укажите его настоящий путь. Итог появится в dist/ после успешных тестов и проверки.

Для интерактивного запуска:
~~~sh
xcodegen generate
open NotesApp.xcodeproj
~~~

Выберите схему NotesApp и симулятор iPhone. Приложению не нужны внешние серверы или сторонние библиотеки.

На Windows можно проверять архив и тесты упаковки при установленном Python 3:
~~~powershell
python -B -m unittest discover -s scripts/tests -v
python -B scripts/validate_ipa.py NotesApp.ipa
~~~

Xcode на Windows не запускается.

## Как создать резервную копию
- **Исходники:** скопируйте папку NotesApp в другое место. В ней нет ваших заметок с телефона.
- **Важные записи:** откройте заметку и сохраните текст отдельно через «Поделиться». Общего экспорта архива пока нет.
- **Телефон:** создайте резервную копию iPhone средствами Apple. Восстановление приложения со сторонней подписью может потребовать повторной установки.
- Файл minimal_notes.json находится в закрытой папке приложения и не доступен через обычный Проводник Windows.
- Не удаляйте приложение и не меняйте его идентификатор, пока не сохранили нужные записи.

## Проверка на телефоне
После подписи проверьте установку и запуск, создание заметки, ввод русского текста и эмодзи, поиск, закрепление, отправку и возврат в редактор. Введите последние символы и сразу уйдите на главный экран; после возврата и повторного запуска текст должен сохраниться. Удаление всех записей не должно возвращать демонстрационную заметку.
