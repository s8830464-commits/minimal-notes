# Правила работы с NotesApp

## Назначение
NotesApp («Заметки», Minimal Notes) — небольшое приложение для локальных текстовых заметок на iPhone и iPad. Корень проекта — папка NotesApp с project.yml и .git. Родительская папка «Санечка» служит контейнером.

## Требования пользователя
- Исправить обнаруженные ошибки и подготовить сборку для проверки на iOS 27.2 beta.
- Пользователь самостоятельно подписывает IPA и устанавливает его через 3uTools или аналогичную программу.
- Документация должна быть на русском языке, понятной без опыта программирования.
- Перед работой прочитать AGENTS.md, PROJECT_STATUS.md и README.md; обновлять состояние после существенных изменений.

## Технологии и структура
- Swift, SwiftUI, UIKit, Combine, Foundation.
- Sources/ — модель заметки, хранение, список, редактор и вход приложения.
- Resources/Info.plist — настройки приложения.
- project.yml — описание проекта для XcodeGen.
- .github/workflows/build_ipa.yml — сборка неподписанного IPA на macOS в GitHub Actions.
- NotesApp.ipa — существующий результат старой сборки; он не доказывает соответствия текущим исходникам.

## Ограничения и данные
- Заметки хранятся в Documents/minimal_notes.json внутри приложения на телефоне.
- Сохранять совместимость с существующим JSON и идентификатором com.ivan.minimalnotes. Изменение идентификатора или команды подписи может повлиять на обновление установленного приложения.
- Перед изменением формата хранения предусмотреть резервную копию и проверку чтения старых данных.
- Не удалять приложение на телефоне для устранения ошибки установки без сохранения заметок.
- Не перезаписывать исходный IPA результатом диагностики и не выдавать старую сборку за новую.
- Не сохранять пароли, ключи, cookies, сертификаты, профили подписи и другие секретные данные в документации или репозитории.
- Подпись и ввод Apple ID выполняет пользователь в выбранном приложении.
- Не запускать push_to_github.bat автоматически: он меняет удалённый адрес и отправляет все добавленные файлы.
- Перед отправкой изменений в GitHub показывать конкретные изменения и получать разрешение пользователя.
- Не заявлять, что исправлены все ошибки или подтверждена совместимость с beta без сборки и проверки на целевом устройстве.
- Не заменять проверку совместимости простым изменением номера MinimumOSVersion.

## Запуск и проверки
Для сборки нужны macOS, Xcode с нужным SDK и XcodeGen. На Windows можно редактировать код и проверять структуру IPA, но Xcode здесь не запускается.

Существующий способ сборки на Mac:
1. Установить Xcode и XcodeGen (при установленном Homebrew: brew install xcodegen).
2. Выполнить xcodegen generate.
3. Открыть NotesApp.xcodeproj в Xcode для запуска на симуляторе.
4. Сборку IPA выполнять по командам из README.md или workflow.

Перед сборкой устранить конфликт генерации Info.plist, описанный в PROJECT_STATUS.md.
Проверки: целостность ZIP, Payload/NotesApp.app, Info.plist, архитектура arm64 для iPhoneOS; затем сборка Xcode, сохранение и повторное открытие заметок, установка подписанного результата на телефон.
