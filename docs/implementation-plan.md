# Согласованные исправления NotesApp

Дата: 12 октября 2026 года. Пользователь подтвердил: «Да, исправляй по этому плану».

## Цель и границы
Исправить обнаруженные дефекты хранения и сборки, сохранить функции, существующий JSON и Bundle ID, собрать неподписанный IPA для самостоятельной подписи и проверки на iOS 27.2 beta. Не добавлять синхронизацию, внешние сервисы или новый дизайн.

## Решение
- NotesFileStore отвечает за чтение и атомарную запись JSON. Отсутствие файла отличается от существующего пустого архива и ошибки чтения.
- NotesViewModel работает на главном акторе, передаёт неизменяемые снимки на последовательную очередь записи и учитывает порядок завершения операций.
- Редактирование блокируется после ошибки чтения. Ошибка записи оставляет изменённые заметки в памяти и позволяет повторить сохранение.
- Отложенная запись отменяется при новых изменениях. Уход из активного состояния и выход из редактора сохраняют последний снимок.
- Формат дат/полей JSON и com.ivan.minimalnotes остаются прежними.
- Редактор связан с единственным источником текста. NavigationStack используется на iOS 16+, прежний NavigationView остаётся для iOS 15.
- Info.plist хранится как исходный файл; XcodeGen не генерирует его заново.
- Сборка требует SDK и симулятор iOS 27.2, запускает тесты и проверяет неподписанный IPA для arm64/iPhoneOS.
- Подпись и установка остаются действиями пользователя.

## Проверки и приёмка
XCTest: старый JSON, отсутствующий/пустой/повреждённый файл, повторный запуск после удаления всех заметок, последние изменения до окончания задержки, порядок записи, ошибки записи и чтения, очистка одного черновика, поиск.
Python: структура пакета, платформа, SDK, подпись, исполняемые права, сохранение метаданных.
Финальная приёмка: установка подписанного выходного файла и проверка сохранности заметок на реальном iPhone с iOS 27.2 beta.

## Ограничения
Локальная Windows не выполняет SwiftUI/Xcode. Успех статических проверок не подтверждает работу на устройстве. Минимальная iOS 15 в настройках не заменяет тестирование каждой старой версии.
